1. 잘못된 방향으로 코딩/학업 공부를 함
실제로 겪은거(코딩): (vulkan, PCG, Custom Game Engine)남들과 다른방향으로 가서 차별점을 바로 만드려고함. 원래는 실력과 기본기를 좀 쌓고 해야하는데
실제로 겪은거(공부): 이거는 그냥 전부터 안해서 그런거.

- 왜 이럴까?
내가 원하는게 지금 기술대비 너무 고차원임.
그리고 무엇보다 묵묵함 인내심이 부족함.

- 예시
"코딩을 할떄 남들과 다른길을 가고싶다." -> 
"게임엔진을 만들고 싶어!" -> 
"처음에는 AI를 사용하여 코드는 읽지않고 그냥 잘 돌아가는지 그리고 디버깅이랑 큰설계만 좀 함." ->
"일단 돌아가기는 돌아 가니까 내가 AI좀 쓴다고 착각" ->
"이후 점점 엔진이 커질수록 나 자신이 AI를 잘쓰고 있는게 맞나? 라는 생각에 빠짐." ->
"그러다가 AI랑 인간의 소유권 문제로 큰 고민을 함(솔직히 이게 기본기 꽤 쌓이고 이러는거면 모르는데, 기본기가 부실한 상태에서 이러니까 문제)" ->
"이후에 하는 프로젝트에서 AI와 인간에 소유권 문제로 크게 고민하다가 결국 아무것도 못함" ->
"그래도 7개월 동안 게임엔진프로젝트라서 얻은건 있겠지~" ->
"코드 싹다 AI가 짠거라서 내가 건진게 설계 적당히 하는거밖에 없음" -> 
"그래서 이후 프로젝트를 손코딩으로 시도하려고 해도 기본기가 부실해서 안됨" -> 
"이걸 9개월 10개월 정도해서 힘 다 빠짐"

2. 이후 힘이 다 빠져서 심하게 지침.
3. 게임으로 도피및 무기력이 쎄게 옴.
4. 게임도 지쳐서 결국 심각한 정체기에 빠짐.
